Frequently Asked Questions

Everything You Need to Know

Common questions about save compatibility, safety guarantees, and game mechanics.

Does this Save Editor support both Steam and Xbox Game Pass PC? ▾
Yes! The editor features automatic platform detection. It locates standard Steam .whs files in %USERPROFILE%\Saved Games\kingdomcome2\saves\ as well as Microsoft Store / Xbox Game Pass WGS (Windows Gaming Storage) encrypted container directories with zero manual configuration.
Can I resurrect dead story characters or fix broken quests? ▾
Absolutely. The integrated Quest Log & Character Fates module allows you to track key NPCs (Sir Radzig, Sir Hans Capon, Father Bohuta, Theresa, etc.) and restore them to 'Alive' status in 1 click. You can also advance stalled objectives or reset quest states.
How does the 5,604-item Codex Spawner work? ▾
The editor bundles the complete Kingdom Come: Deliverance II official item database. You can search by English or German names, filter by category (Weapons, Armor, Food, Potions, Horse Tack, Books), set condition to 100%, and choose whether to deposit into Henry's inventory, personal chest (stash), or horse saddlebags.
Will editing my save corrupt my files or get me banned? ▾
No. The native C++20 engine strictly recalculates CryEngine's internal 64-byte XMLCPB trailer and RFC 1321 MD5 integrity checksums. Furthermore, every single save action automatically creates a timestamped safety backup (.bak), ensuring your original files are 100% protected.
Is this save editor free and open-source? ▾
Yes, 100% free and open-source under the permissive MIT License. There are no ads, paywalls, or premium tiers. The source code and automated build workflows are publicly available on GitHub.
